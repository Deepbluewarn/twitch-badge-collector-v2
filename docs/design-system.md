# 확장 UI 디자인 규칙

팝업·설정 페이지(필터·템플릿)의 디자인 기준. 배지 사이트(badgecollector.dev)와 같은 언어를 쓴다.
2026-10-17 시안 비교로 확정했다. 시안 원본은 브랜치 `prototype/design-refresh-theme`(채택),
`prototype/design-refresh-structure`(구조 개편안, 기각)에 있다.

치지직·트위치 페이지 안의 모아보기 컨테이너는 대상이 아니다 — 호스트 페이지의 테마를 따른다.

## 원칙

- 흰 종이 + 형광펜 노랑 + 검정 잉크. 그림자·그라데이션 대신 굵은 선(2px)과 노란 면으로 나눈다.
- **굵은 외곽선은 가장 바깥 상자 하나만.** 그 안은 선(머리 아래 2px, 줄 사이 1px)이나 옅은 면으로 나눈다. 상자 안에 상자 테두리를 겹치지 않는다.
- 화면 구조는 기존 그대로 두고 모양만 바꾼다 (구조 개편안은 기각).
- **화면에 설명 문구를 달지 않는다.** 이름표·자리표시자·버튼 글자만. 이름표 옆 힌트, 구획 설명, 툴팁도 넣지 않는다.

## 색

| 토큰 | 밝게 | 어둡게 | 쓰임 |
|---|---|---|---|
| paper | `#ffffff` | `#161512` | 바탕 |
| ink | `#111111` | `#f4f1e6` | 글자 |
| yellow | `#ffd60a` | `#ffd60a` | 주 버튼, 선택된 칸, 탭 밑줄, 현재 페이지 |
| on-yellow | `#111111` | `#111111` | 노란 면 위 글자 (테마와 상관없이 검정) |
| line | `#111111` | `#6a665a` | 버튼·입력·카드 테두리 |
| rule | `#111111` | `#6a665a` | 구획 굵은 선 (표 머리 아래). 어둡게에서 글자색 2px는 너무 밝다 |
| hair | `#e7e5df` | `#2c2a25` | 줄 사이 얇은 선 |
| tint | `#f5f4ef` | `#23211c` | 옅은 면 (카드 안 칸, 타일) |
| canvas | `#f4f4f5` | `#161512` | 설정 페이지 바탕. 흰 카드(paper)가 떠 보이게 한 단 낮춘 중성 회색 (미색은 흰 카드와 색온도가 부딪혀 기각). 팝업은 paper 그대로 |
| soft | `#fff6c2` | `#3b3413` | 마우스 올린 줄, 포커스된 입력 |
| muted | `#6b6a66` | `#a19d90` | 보조 글자 |

다크는 단순 반전이 아니다 — 흰 굵은 선이 거칠어서 테두리는 낮춘 크림(line)으로 둔다.

**상태 색** (필터·조건 공통, 테두리 없는 옅은 면 + 진한 글자)

| 상태 | 밝게 글자 | 어둡게 글자 | 면 |
|---|---|---|---|
| 포함 / 맞음 | `#137a47` | `#5fd39a` | 초록 12% (어둡게 20%) |
| 제외 / 아님 | `#c22b31` | `#ff8a8e` | 빨강 10% (어둡게 22%) |
| 꺼짐 | muted | muted | 잉크 7% |

## 글자

Pretendard Variable. 대체 글꼴 순서는 페이지 body와 같게 둔다(-apple-system, BlinkMacSystemFont, system-ui, …, Noto Sans KR, Malgun Gothic).

| 단계 | 크기 / 굵기 | 쓰임 |
|---|---|---|
| 제목 | 20 / 900 | 카드·대화상자 제목 |
| 버튼 | 14 / 800 | 버튼 |
| 보조 | 13 / 700 | 표 주변 동작(선택 해제·모두 선택·선택 삭제), "+ 조건/채널/메모", 조건 칩, 페이지 번호, 푸터 |
| 이름표 | 13 / 800 | 입력칸 위 이름표, "N개 선택" |
| 태그 | 12 / 800 | 상태 태그 |

## 컴포넌트

- **버튼**: 높이 40, 모서리 8, 테두리 2px.
  - 주: 노란 면. 올리면 잉크 면 + 노란 글자(어둡게는 밝은 노랑).
  - 보조: paper 면 + line 테두리. 올리면 잉크 면.
  - 위험(선택 삭제): 빨간 테두리·글자, 올리면 빨간 면 + 흰 글자.
- **토글 묶음**: 묶음 전체에 2px 테두리, 칸 사이 2px 선, 선택된 칸 노란 면. 칸 폭은 내용만큼(늘이지 않는다).
- **스위치**: 트랙 2px 테두리. 켜지면 노란 트랙 + 검정 손잡이.
- **입력칸**: 2px 테두리, 포커스되면 soft 면. 이름표는 칸 위에(칸 안에 떠 있는 라벨 대신).
- **탭**: 밑줄 4px 노랑, 선택된 탭 잉크 글자.
- **대화상자·팝업·메뉴**: 2px 테두리(그림자가 없으니 테두리로 띄운다). 대화상자 안의 카드는 테두리 없이 tint 면. 채널·메모 대화상자는 폭 고정(xs), 버튼은 [취소: 보조] [저장/추가: 주].

## 필터 목록 (표 F)

한 줄(높이 44) = 필터 하나. 바깥 카드 안에서 표 자기 테두리는 없다 — 머리 아래 2px rule 선, 줄 사이 hair.

```
[☐] [■색] [배지 스트리머] + [“키워드”]  + 조건        채널 X  메모 Y  [포함]
```

- **체크박스**: 맨 왼쪽 세로줄. 전체 선택도 같은 세로줄 맨 위(메일함 방식).
  - 안 골랐을 때: "필터 N개".
  - 골랐을 때: "N개 선택 · [선택 삭제] … 선택 해제". 이 페이지를 다 골랐고 페이지가 더 있으면 "필터 N개 모두 선택".
- **수집 표시 색**: 포함 필터만 20px 네모 칸. 누르면 팔레트 팝업(9색 + 직접 고르기). 툴팁 없음.
- **조건 칩**: 테두리 없는 둥근 옅은 면, 상태 색(맞음/아님/꺼짐). 배지는 그림 + 이름, 이름 `@x`, 키워드 `“x”`. 조건 사이 `+`. 누르면 편집, ✕는 그 칩에 올렸을 때만.
- **채널·메모**: 값이 있으면 "채널 X"(누르면 편집, ✕는 올렸을 때). 없으면 "+ 채널 / + 메모" 글자 링크를 줄에 올렸을 때만.
- **상태 태그**: 오른쪽, 네모 모서리, 상태 색. 누를 때마다 포함 → 제외 → 꺼짐.
- **페이지**: 기본 10개, "페이지당 10 · 20 · 50 · 100"(storage.local `filterListPageSize`). 필터가 10개 이하면 숨긴다. 번호는 `‹ 1 … 5 6 [7] 8 9 … 20 ›`, 현재 페이지 노란 칸.
- **가져오기·내보내기**: 표 위 글자 링크가 아니라 머리의 보조 버튼 — `[필터 가져오기] [필터 내보내기] [+ 새 필터 추가]`.

## 설정 페이지 (Chrome 설정형)

2026-10-25 시안 비교로 확정했다(시안 원본: 브랜치 `prototype/settings-ui`의 B). 필터 설정·일반 설정·채팅 모양·채팅 보관함 네 화면이 같은 틀을 쓴다.
부품은 `src/components/settings/SettingsUI.tsx`, 틀은 `src/components/SettingLayout.tsx`.

- **틀**: 위쪽 막대(아이콘 + "설정", 설정 검색), 왼쪽 글자 메뉴(현재 화면은 soft 면 + 왼쪽 노란 막대), 가운데 열(최대 1040px)에 화면 제목(22 / 900).
  좁은 창(760px 이하)에서는 메뉴가 위쪽 탭 줄이 된다.
- **묶음**: 묶음 제목(15 / 900) + 가는 테두리(1px hair) 카드. 카드 안은 "이름표 왼쪽 / 컨트롤 오른쪽" 줄(높이 56 이상), 줄 사이 hair.
  이 화면들의 카드는 굵은 외곽선 대신 가는 선을 쓴다 — 줄이 많아서 2px 상자는 무겁다.
- **하위 페이지**: 누르면 들어가는 줄은 오른쪽에 `›`. 들어가면 [← 뒤로] + 제목 + 오른쪽 동작(HTML 직접 편집, 보관함의 채널).
- **버튼**: 모두 작은 크기(sm). 주 버튼(노랑)은 화면마다 하나 — 필터 설정의 "새 필터 추가", HTML 편집의 "저장", 대화상자의 확인.
  나머지는 보조, 되돌리기·지우기 같은 가벼운 동작은 글자 버튼.
- **플랫폼 표시**: 한 플랫폼에서만 동작하는 설정·메뉴는 이름 옆에 플랫폼 칩(트위치 `#9146ff`, 치지직 `#00ffa3` 점 + 16% 면).
  필터 설정은 플랫폼 색을 포인트로만 쓴다 — 고른 칸, 목록 카드 위 3px 띠, 목록 제목 옆 칩.
- **검색**: 메뉴 이름과 일반 설정 줄을 찾는다. 결과의 일반 설정 줄은 그 자리에서 바로 바꿀 수 있고, 위에 "일반 설정 › 묶음"을 붙인다.
- 카드 아래 작은 글(Note)은 면책·범위처럼 꼭 알려야 하는 것만.

## 구현

MUI는 걷어냈다(2026-10-17). 부품은 `src/ui/` — 버튼(주/보조/글자/위험), 아이콘 버튼, 토글 묶음, 스위치,
입력·선택·여러 줄 입력, 카드, 탭, 대화상자, 알림, 태그, 스피너. 색은 `src/ui/tokens.css` 토큰만 쓴다.
페이지 진입점에서 `useDocumentTheme(isDark)`를 부르면 바탕 스타일(`base.css`)을 싣고 `<html data-theme>`을 맞춘다.
아이콘은 각 페이지 html이 불러오는 Material Icons Round 글꼴의 이름(`<Icon name="add" />`).

- 대화상자가 겹쳐 열리면 맨 위 것만 Esc를 받는다. 열릴 때 한 번 첫 입력칸에 초점.
- 카드 안·대화상자 안의 카드는 자동으로 테두리 없는 옅은 면 (외곽선 겹침 방지).
- 콘텐츠 스크립트(모아보기 컨테이너)는 `src/ui`를 쓰지 않는다 — 호스트 테마를 따르는 자체 CSS(`tbcv2-` 접두사).
