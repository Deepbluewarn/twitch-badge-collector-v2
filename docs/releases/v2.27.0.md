# v2.27.0

v2.26.0 이후 변경 사항. Chrome과 Edge에 익명 사용 통계를 넣었다. 결정과 이유는 [ADR 0001](../adr/0001-anonymous-usage-stats.md).

Firefox 빌드에는 통계 코드가 들어가지 않아 달라지는 것이 없다. 예약 작업이 버전만 올려 제출한다.

## 1. 릴리스 노트

```
v2.27.0

- 익명 사용 통계 추가 (Chrome, Edge. 기능별 사용 여부만 수집, 설정 > 일반 설정 > 익명 사용 통계에서 끌 수 있음)
```

## 2. 변경

- **기록과 전송** (`src/telemetry/`):
  - 하루 기록: 확장을 쓴 날마다 하나. 그날 한 일 18가지(`flags.ts` `USAGE_FLAGS`)를 0/1로 적는다.
  - 주간 기록: 그 주에 처음 쓴 날 하나. 설정을 기본값에서 바꿨는지 25가지(`SETTING_FLAGS`)와 언어. 설정은 날마다 같아서 매일 보내면 기록을 잇는 단서가 되므로 주에 한 번 따로 보낸다. 필터는 설치 때 들어가는 기본 필터를 빼고 센다.
  - 날짜가 바뀐 뒤 처음 표시할 때와 브라우저를 켤 때 지난 기록을 `badgecollector.dev/api/ping`으로 몰아 보낸다(`text/plain`, preflight 없음). 보낸 건 지우고, 5xx나 네트워크 오류면 6시간 쉬었다가 다시 보낸다. 7일 넘은 기록은 버린다.
  - 저장소에 쓰는 건 백그라운드 하나(`usage-stats.ts`). 콘텐츠 스크립트와 페이지는 `markUsage`로 메시지만 보낸다(`usage-mark.ts`, 페이지마다 하루 한 번). `markUsage`는 무슨 일이 있어도 던지지 않는다(연결이 끊긴 옛 스크립트의 `sendMessage` 예외 포함).
  - 설치 ID, 사용 횟수, 설정값, 채널, 닉네임, 채팅은 보내지 않는다.
- **표시 위치**: 모아보기 창(플랫폼, 수집, 다시보기, 맨 아래로), 필터 저장(내용이 바뀔 때만), 템플릿 저장, 보관함(열기, 검색, 내보내기), 캡처, 설정과 팝업 열기, 팝업의 채팅 비우기와 비율 초기화, 경계선 끌기, 치지직 프로필 ID 복사, 채널 끄기.
- **설정** (`GeneralSetting.tsx`): 일반 설정 맨 아래 "개인정보" 묶음. 익명 사용 통계 스위치(기본 켬)와 [보기](보낼 기록 그대로, 처리방침 링크). 끄면 모아 둔 기록을 바로 지운다. Firefox 빌드에는 묶음이 없다.
- **권한**: 추가 없음. 업데이트 때 승인 창이 뜨지 않는다.

확장 밖:
- 사이트 `functions/api/ping.ts`: 확장 ID(Chrome, Edge) Origin, 형식, 날짜, 건수를 검사해 Cloudflare Analytics Engine `tbc_usage`에 쓴다. IP는 남기지 않는다. Cloudflare 속도 제한 규칙 `/api/ping`.
- 처리방침: `https://badgecollector.dev/extension/privacy/` (시행일 2026-11-05). 옛 `privacy.badgecollector.dev`는 301로 넘긴다.
- ovm: 현황판(:3400)에 확장 사용자, 기능 사용, 설정 칸(`usage` 작업, 3시간). Discord 하루 리포트엔 사용자 수 한 줄. 실제 릴리스 버전의 기록만 센다.
- 스토어: Chrome 개인정보 탭 신고 완료, 설명에 개인정보 단락 추가. Edge는 지금 심사 중이라 끝난 뒤에 같은 내용으로.

## 3. 확인

- **테스트:** vitest 554개 통과, tsc 오류 없음
- **Firefox 빌드:** 통계 코드, 문자열 없음 확인
- **실제 Chromium(빌드 올려서):** 치지직 방송, 설정, 팝업을 열면 하루 기록에 표시가 남고, 주간 기록이 함께 만들어짐(미리 켠 시간 표시가 1, 언어 ko). 어제 기록은 날짜가 바뀌자 바로 전송
- **서버:** 정상 기록 204(Chrome, Edge), 다른 출처와 목록 밖 확장 ID 403(확장이 읽고 바로 버림), 형식 오류 400, 속도 제한 429
- **실제 업데이트 시험:** 릴리스 전에 한다(CLAUDE.md 절차, 스토어 v2.26.0 → 이 빌드)
