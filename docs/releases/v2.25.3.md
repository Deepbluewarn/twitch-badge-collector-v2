## 2. 변경

- **채팅 최대 개수 칸** (`GeneralSetting.tsx`): 입력 중인 값을 따로 들고, 1 이상의 정수일 때만 저장한다. 칸을 벗어나면 저장된 값으로 되돌린다.
- **필터 가져오기** (`src/filter/import.ts`): 항목마다 형식을 검사해 틀린 항목은 빼고 개수를 알린다. JSON이 아니면 알리고 그대로 둔다. 비우고 하나씩 넣던 것을 한 번에 바꾼다. 판정은 값이 문자열이 아닌 조건을 건너뛴다.
- **차단한 사용자** (`rest-tap.ts`, `chzzk-archive-feed.ts`): 차단 목록은 페이지를 열 때 한 번만 오고 콘텐츠 스크립트는 대개 그 뒤에 떠서 놓쳤다. REST 탭이 마지막 목록을 기억했다가 요청하면 다시 보낸다. 보관함도 차단 목록을 본다.
- **모아보기 성능** (`useFilteredChatBuffer.tsx`): 이미 그린 채팅은 다시 정화하고 파싱하지 않는다.
- **채팅 유지 저장** (`chat-history-store.ts`):
  - 전체 한도 4MB를 채널 수 한도만큼(20MB)으로. 1MB 가까운 탭이 5개를 넘으면 2초마다 서로 지웠다.
  - 1MB를 넘으면 잰 크기로 한 번에 덜어 낸다. 크기 초과가 아닌 오류에는 줄이지 않는다.
  - 치지직(새 채팅이 위)에서 덜어 낼 때 최신 채팅을 버리던 것.
- **채널 검색 인증 마크** (`chzzk-channel.ts`, `ChannelSearch.tsx`): `verifiedMarkType`으로 마크 그림을 고른다.
- **치지직 캡처 선택** (`useFilteredChatBuffer.tsx`): 소켓 채팅을 치지직 원본 모양으로 그리면 원본의 `data-tbc-chat-key`(끝에 UUID)가 남아 확장이 쓰는 key(소켓 id)와 달랐다. 클릭 선택과 PNG는 속성으로, 선택 표시와 전체 선택은 key로 찾아 서로 어긋났다. 소켓 모드가 100%라 치지직 캡처 사용자 대부분이 겪었다. 모아보기 창에 그릴 때 속성을 key로 맞춘다. 릴리스 전 확인 중에 찾았다(v2.25.2에도 있음).
- **채팅 모양** (`TemplateSetting.tsx`): 템플릿으로 표시가 꺼져 있으면 모양 불러오기, 공유, HTML 직접 편집, 미리보기를 숨기고 스위치만 둔다. 꺼진 채로 고쳐도 채팅에 보이지 않아 헷갈렸다.
- **진단 보고** (`report.ts`, `diagnose.ts`): HTML 속성 값은 class, role, type, aria-hidden만 남기고 비운다. 필터 요약은 종류만 보낸다.
