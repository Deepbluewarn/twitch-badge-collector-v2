## 2. 변경

- **요약** (`public/_locales/ko/messages.json` d6502da, `public/_locales/en/messages.json` 8be788f): manifest `description`으로 쓰여 스토어 검색 결과 설명에 나온다. 치지직, 뱃지 같은 검색어를 넣었다.

  - 스토어 상세 설명은 대시보드에서 따로 바꾼다.
