# v2.25.0

v2.24.1 이후 변경 사항. 채팅 보관함과 채팅 모양 세부 설정을 새로 넣고, 설정 페이지를 다시 짰다. 치지직 인증 마크가 세 종류로 나뉜 것을 반영했다.

## 1. 릴리스 노트

```
v2.25.0

- 채팅 보관함: 라이브에서 필터에 걸린 채팅을 채널별로 브라우저에 따로 저장 (기본 꺼짐, 설정에서 켜기)
- 채팅 모양: 템플릿 표시를 켜면 글꼴, 크기, 색, 간격, 배경 등을 부분별로 설정, 모양 코드로 공유
- 설정 페이지 개편: 왼쪽 메뉴와 설정 검색
- 채널별로 끄면 수집과 보관까지 멈추고 채팅창도 원래대로
- 치지직 인증 마크가 파트너, 챌린저, 공식으로 나뉜 것을 반영. 기존 '인증 마크' 필터는 '파트너 마크'로 바뀜
- 모아보기 시각 표시와 여백 다듬기
- 치지직에서 다른 채널로 이동했을 때 채널 지정 필터가 이전 채널 기준으로 적용되던 문제 수정
- 소켓 모드에서 업데이트 직후 채팅이 두 번 들어가던 문제 수정
```

## 2. 주요 변경

- **채팅 보관함** (`src/archive/`): 치지직 라이브는 모아보기 창과 떼어 소켓에서 바로 기록한다. 끊긴 구간을 표시한다. 보관 기간 7, 30, 90, 365일, 용량 상한 600MB(30일까지), 1.2GB, 2GB. 크롬은 `unlimitedStorage` 권한 추가(승인 창 없음), Firefox 빌드는 뺀다. 기본 꺼짐.
- **채팅 모양** (`src/render/chzzk-style.ts`, `chzzk-chat.css`): 직접 그린 채팅의 기본 모양을 치지직 원본(20채널 실측)에 맞추고, 부분별 스타일 설정과 모양 코드 공유를 넣었다. 배지 숨김은 CSS로(이미 그려진 채팅에도 적용), 카드 배경은 일괄 설정 하나, 금액별 모양은 HTML 변수 `donation.level`.
- **설정 페이지**: Chrome 설정형 구성, 고르기 상자를 Radix Select로.
- **인증 마크** (`src/platform/chzzk-verified.ts`): 소켓은 `verifiedMarkType`, 원본 HTML은 마크 요소 class로 종류를 알아보고 종류별 URL을 이름표로 붙인다. 예전 '인증 마크' 필터는 설치, 업데이트, 백업 가져오기 때 '파트너 마크'로 바꾼다.

## 3. 업데이트 때 옮기는 것 (background `onInstalled`)

- 템플릿 '크게' → 스타일 글자 크기, 예전 후원 템플릿 → 새 후원 템플릿, 배지 없는 템플릿 → 배지 숨김 스타일
- 필터의 '역할: 인증 마크' → '역할: 파트너 마크'
- 치지직 배지 목록 보관본(7일) 비우기

## 4. 배포 순서

1. `data/chzzk-badges.json`(역할 그룹: 파트너, 챌린저, 공식 마크)을 릴리스와 같은 날 커밋하고 jsDelivr purge. 먼저 나가면 옛 버전 사용자가 고른 새 마크 필터가 걸리지 않는다.
2. GitHub 릴리스 v2.25.0 → `publish.yml`
