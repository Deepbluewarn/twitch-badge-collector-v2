# v2.31.0

v2.30.1 이후 변경 사항. 팝업 하단을 정리하고, 다시보기 되감기 문제를 고치고, 후원 링크를 Fairy로 넣었다.

## 1. 릴리스 노트

```
v2.31.0

- 팝업 하단을 한 줄로 정리하고, 진단 기능을 문의 링크로 대체
- 다시보기를 되감은 뒤 다시 지나간 채팅이 수집 창에 들어가지 않던 문제 수정
- 팝업과 설정 페이지에 후원 링크 추가
```

## 2. 변경

- **팝업 하단** (`src/entrypoints/popup/main.tsx`, `src/utils/site-link.ts`, d6543ad): 비율 초기화, 사용 설명서, 문의를 한 줄로 합쳤다. 문의는 badgecollector.dev/contact/를 버전과 브라우저를 붙여 연다. 설명서와 문의 페이지가 한국어뿐이라 한국어가 아닌 브라우저는 예전처럼 Discord, GitHub, 메일 아이콘. 진단 기능(`src/platform/diagnose.ts`, `report.ts`)과 콘텐츠 스크립트의 진단 응답을 지웠다.
- **다시보기 되감기** (`src/hooks/useChatStream.ts`, `src/components/Extension/Local.tsx`, bcb7c76, 69579f7):
  - 되감기로 수집 창을 비울 때 처리 기록(seenKeys)이 남아, 같은 채팅이 다시 지나가면 원본에 수집 표시만 붙고 창에는 들어가지 않았다. 되감을 때 처리 기록도 지운다(사용자가 창을 비울 때는 지우지 않는다).
  - 지금 시각을 탐색할 때만 갱신해서, 한 번 탐색한 뒤 쭉 재생하다 되감으면 되감기로 보지 않았다. 재생 중에도 따라가고(timeupdate), 비우기는 탐색이 시작될 때(seeking) 한다.
- **후원 링크** (`src/components/DonateHeart.tsx`, `src/entrypoints/popup/main.tsx`, `src/components/SettingLayout.tsx`, 1a0bc9c, 7b18df5): 팝업 헤더 버전 표시 옆에 빨간 하트, 설정 페이지 왼쪽 메뉴 badgecollector.dev 아래에 "후원". Fairy(fairy.hada.io/@badge-collector)로 간다. 후원 페이지가 한국어뿐이라 한국어 브라우저만. 처음 그릴 때 한 번 흔들고 올리면 속이 찬다. 동작 줄이기 설정이면 흔들지 않는다.
- **권한**: 추가 없음.
