# v2.28.0

v2.27.0 이후 변경 사항. 사용 설명서(badgecollector.dev/extension/guide/)로 가는 링크를 팝업과 빈 수집 창에 두고, 치지직 채팅 모양의 후원과 선물 표시를 고쳤다.

## 1. 릴리스 노트

```
v2.28.0

- 사용 설명서 링크 추가 (팝업 맨 아래, 수집 창이 비었을 때)
- 치지직 채팅 모양에서 미션 참여 후원과 받는 사람을 고른 구독 선물 표시 개선
- 채팅 최대 개수 설정의 "새로고침 필요" 표시 삭제 (바꾸면 바로 적용)
```

## 2. 변경

- **사용 설명서 링크** (`src/utils/site-link.ts`, `src/entrypoints/popup/main.tsx`, `src/components/Extension/Local.tsx`):
  - 팝업 맨 아래 줄 왼쪽에 "사용 설명서"(책 아이콘). 오른쪽은 원래 있던 Discord, GitHub, 메일.
  - 수집 창이 비어 있고 캡처 중이 아닐 때만 가운데에 흐리게 "수집된 채팅 없음"과 그 아래 "사용 설명서" 링크. 채팅이 하나라도 수집되면 사라진다. 글자색은 호스트 글자색을 따른다.
  - 설명서가 한국어로만 있어 한국어 브라우저에서만 보인다. 문자열은 ko, en만 넣었다(영어는 보이지 않지만 기본 로캘이라 둔다).
  - GA 출처: `utm_content=popup_guide`, `empty_pane`. 팝업 로고 링크의 `popup`과 나눈다.
- **익명 사용 통계** (`src/telemetry/flags.ts`): 하루 기록에 `guideOpen`(사용 설명서 링크를 누른 날)을 덧붙였다. 하루 기록의 숫자 칸이 20개를 넘어 서버가 `day2` 행으로 나눈다.
- **치지직 채팅 모양** (`src/render/chzzk-templates.ts`, `chzzk-render.ts`, `chzzk-chat.css`):
  - 미션 참여 후원(MISSION_PARTICIPATION)을 일반 후원 카드가 아니라 host처럼 "○○님이 / 미션 이름 미션에 / 금액 추가했습니다."로 그린다. 템플릿 값 `donation.participation` 추가.
  - 받는 사람을 고른 구독 선물(SUBSCRIPTION_GIFT_RECEIVER에 보낸 사람 profile이 있을 때)은 "보낸 사람님이 / 받는 사람님에게"로 그린다.
  - 기본 선물 템플릿이 바뀌어, 업데이트 때 예전 후원, 선물 템플릿을 지금 것으로 옮긴다(`migrateLegacyTemplates`, 예전 `migrateLegacyDonation`).
- **설정** (`src/components/GeneralSetting.tsx`): 채팅 최대 개수 옆 "새로고침 필요"를 뺐다. 수집 창은 최대 개수를 ref로 읽어 다음 채팅부터 바로 적용한다.
- **권한**: 추가 없음.

확장 밖:
- 사이트 `functions/api/ping.ts`: `guideOpen`을 받는다. v2.27.0이 보내는 20칸 뒤에 덧붙인 항목은 빠져 있어도 기록을 받는다(옛 버전 기록이 버려지지 않게). 2026-11-08 배포.
- ovm `usage` 집계: `day2` 행도 읽고, `guideOpen` 비율은 `day2` 행 수로 나눈다.
- 사이트 사용 설명서: `/extension/guide/`. 사진은 `docs/guide-images/capture.mjs`로 찍는다.
