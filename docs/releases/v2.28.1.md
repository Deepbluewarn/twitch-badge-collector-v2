# v2.28.1

v2.28.0 이후 변경 사항. 빈 수집 창 가운데의 "수집된 채팅 없음"과 사용 설명서 링크를 뺐다.

## 1. 릴리스 노트

```
v2.28.1

- 수집 창이 비었을 때 가운데에 뜨던 안내와 사용 설명서 링크 삭제 (사용 설명서는 팝업에서)
```

## 2. 변경

- **빈 수집 창 안내 삭제** (`src/components/Extension/Local.tsx`, `Local.css`, `public/_locales/{ko,en}/messages.json`): v2.28.0에서 넣은 것을 통째로 뺐다. 번역 키 `noCollectedChats`도 지웠다. 팝업의 사용 설명서 링크와 `guideOpen` 통계는 그대로다.
  - 이유: 불편하다는 반응이 많았고, 11-08 설명서 방문 1,246건이 거의 다 이 링크에서 왔는데 75%가 바로 나갔다. 수집 창을 누르다 잘못 눌러 새 탭이 열린 것으로 본다(`docs/reports/2026-11-09-usage-stats-v2.28.0.md`).
- **권한**: 추가 없음.

확장 밖:
- ovm `usage` 집계: `guideOpen` 비율에서 v2.28.0보다 옛 버전 기록을 뺐다(debd043).
- 시험 스크립트 `scripts/real-update-test.mjs`에 `--headless`. SSH로만 접속해 화면이 없을 때 쓴다.

## 3. 확인

- **테스트:** vitest 563개 통과, Chrome, Firefox 빌드 성공. 빌드 결과물에 지운 문자열, 클래스, `empty_pane`이 남지 않았다.
- **실제 업데이트(Chrome 업데이터, 스토어 v2.28.0 zip → 빌드 e710bdd, `--headless`):** 소켓 켬/끔 × 채팅 유지 저장 켬/끔 네 조합 모두, 시청자 3,700명 방송.

  | 소켓 / 채팅 유지 | 업데이트 직후 | 업데이트 뒤 60초 | 새로고침 | 빈틈 7초 |
  |---|---|---|---|---|
  | 끔 / 켬 | 창 하나, 19 유지, 띠 없음 | 25 → 29 | 33 그대로 | 33 유지, 다시 켠 뒤 안내 띠 |
  | 켬 / 켬 | 창 하나, 15 유지, 띠 없음 | 18 → 34 | 35 그대로 | 35 유지, 다시 켠 뒤 안내 띠 |
  | 끔 / 끔 | 창 하나, 15 유지, 띠 없음 | 19 → 23 | 비워짐(정상) | 3 유지, 다시 켠 뒤 안내 띠 |
  | 켬 / 끔 | 창 하나, 16 유지, 띠 없음 | 17 → 37 | 비워짐(정상) | 2 유지, 다시 켠 뒤 안내 띠 |

  - 업데이트 순간 0.4초쯤 창이 없는 지점이 한 번 잡히는 건 v2.25.3부터 있던 창 교체 순간.
  - 빈틈 시험에서 다시 켠 뒤 창의 채팅 수가 0으로 잡히고 안내 띠가 뜬다. 스토어 v2.28.0만 깔고 같은 시험을 해도 같아서 이번 변경과는 무관하다.
