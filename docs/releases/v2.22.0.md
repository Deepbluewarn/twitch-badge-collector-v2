# v2.22.0

v2.21.1(2026-10-15) 이후 변경 사항. `master`의 템플릿·트위치 수정과 `feature/design-refresh`의 새 디자인·필터 시험을 합친 릴리스.

## 1. 릴리스 노트

GitHub Release 본문과 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣는다.

```
- 팝업과 설정 페이지 새 디자인 (어둡게 모드 포함)
- 필터 목록 개편: 한 줄에 필터 하나, 상태별 색, 페이지당 표시 개수 설정(10/20/50/100)
- 필터 시험 추가: 배지·닉네임·채팅을 넣으면 수집되는지 바로 확인
- 치지직 모아보기 채팅 모양을 코드 없이 선택 (배치·배지·글자 크기)
- 채널 주소를 붙여 넣으면 채널 ID 자동 입력
- 치지직 배지 모음 사이트(badgecollector.dev) 링크 추가
- 트위치 모아보기가 새 채팅을 따라 스크롤되지 않던 문제 수정
- 트위치에서 새 채팅이 들어오자마자 사라지던 문제 수정
- 클린봇 원문을 펼치면 줄이 바뀌던 문제 수정
- 템플릿 설정을 다시 열면 고친 내용이 보이지 않던 문제 수정
```

## 2. 달라진 점 안내

### 새 디자인

팝업과 설정 페이지가 badgecollector.dev와 같은 흰 바탕 + 노랑 디자인으로 바뀌었다. 화면 구성과 메뉴 위치는 그대로다. 어둡게 모드도 같은 디자인으로 맞췄다.

팝업 위의 로고와 설정 페이지 아래의 `Badge Collector`를 누르면 badgecollector.dev가 열린다.

### 필터 목록

| 이전 | 지금 |
|---|---|
| 표 칸마다 테두리 | 한 줄 = 필터 하나 |
| 조건이 테두리 칩 | 조건 칩 색이 곧 상태: 초록(포함·맞음), 빨강(제외·아님), 회색(꺼짐) |
| 수집 표시 색을 찾기 어려움 | 포함 필터 앞의 색 칸을 누르면 팔레트 |
| 가져오기·내보내기가 표 위 작은 글자 | 머리의 `새 필터 추가` 옆 버튼 |

- **상태 바꾸기:** 줄 끝의 태그(포함/제외/꺼짐)를 누르면 차례로 바뀐다.
- **조건·채널·메모 추가:** 줄에 마우스를 올리면 `+ 조건` `+ 채널` `+ 메모`가 나온다. 칩에 올리면 ✕로 지운다.
- **여러 개 삭제:** 줄 앞 체크 상자로 고르고 `선택 삭제`. 머리의 체크 상자는 지금 페이지 전체를 고르고, 이어서 나오는 `필터 N개 모두 선택`으로 모든 페이지를 고른다.
- **페이지당 개수:** 아래에서 10/20/50/100 중 고른다. 기본 10개, 고른 값은 기억한다. 표 높이는 10줄로 고정이라 20개 이상이면 표 안에서 스크롤한다.

### 필터 시험

필터를 많이 쓰다 보면 "이 채팅이 왜 안 모이지?"를 알기 어렵다. 필터 목록 위의 `필터 시험`을 누르면 목록 옆에 시험 칸이 열린다(창이 좁으면 목록 아래).

1. `+ 배지`를 눌러 배지를 고른다. 고른 배지를 다시 누르면 빠진다.
2. 닉네임과 채팅 내용을 적는다.
3. 결과가 바로 나온다. 실행 버튼은 없다.

| 결과 | 뜻 |
|---|---|
| **수집됨** (초록) | 모아보기에 들어간다. 옆의 색 칸이 표시 색 |
| **제외됨** (빨강) | 제외 필터에 걸려 들어가지 않는다 |
| **수집 안 됨** (회색) | 맞는 포함 필터가 없다 |

시험 칸이 열려 있는 동안 필터 목록도 결과대로 칠해진다.

- 초록 줄: 이 채팅을 모은 필터
- 빨간 줄: 이 채팅을 막은 필터
- 흐린 줄: 맞지 않는 필터, 꺼진 필터, 다른 채널 필터
- 조건 칩의 ✓ / ✕: 조건이 여러 개인 필터는 **모든 조건이 맞아야** 걸린다. 일부만 맞으면 줄은 흐리고, 어떤 조건이 모자란지 칩마다 ✓ / ✕로 보인다.

필터를 고치면 결과도 바로 바뀐다. 시험 칸을 닫아도 넣은 내용은 남아 있어, 필터를 고친 뒤 같은 채팅으로 다시 확인할 수 있다. 특정 채널에만 쓰는 필터가 있으면 시험할 채널도 고를 수 있다.

### 모아보기 채팅 모양

치지직 전용. 팝업의 `모아보기 채팅 모양 (치지직)`에서 `커스텀`을 고르면 그 아래 `템플릿 설정 →` 링크가 나온다. 템플릿 설정의 `모양`에서 HTML을 몰라도 고를 수 있다.

- 배치: 한 줄 / 두 줄 / 말풍선
- 배지: 표시 / 숨김
- 글자 크기: 보통 / 크게

`HTML 직접 편집`은 접혀 있고, 직접 고친 템플릿이 있으면 펼친 채로 열린다. 쓸 수 있는 값(닉네임, 채팅 내용 등)을 누르면 커서 자리에 들어간다.

### 그 밖에

- **채널 지정:** 채널 주소(`https://chzzk.naver.com/…`, `https://www.twitch.tv/…`)를 통째로 붙여 넣으면 ID만 남는다. ID가 비어 있으면 추가할 수 없다.
- **배지 모음 링크:** 치지직 새 필터 추가의 배지 고르기 위에 `배지 모음 ↗`. 배지 이름과 설명을 사이트에서 찾아볼 수 있다.
- **문구 수정:** 배지 칩의 꺼진 상태가 `제외`로 잘못 나오던 것을 `꺼짐`으로.

### 고친 문제

- 트위치 모아보기가 새 채팅을 따라 내려가지 않던 문제
- 트위치에서 채팅창이 비워진 직후 들어온 새 채팅이 맨 위에 들어가 바로 지워지거나 순서가 뒤집히던 문제
- 클린봇이 가린 채팅의 원문을 펼치면 다음 줄로 내려가던 문제
- 템플릿 설정을 다시 열면 고친 내용 대신 기본값이 보이고, 그대로 저장하면 덮어쓰던 문제
- 배지 고르기에서 고급 설정으로 배지를 고른 뒤 고급 설정을 끄면 선택된 모양이 남던 문제

## 3. 개발 변경 사항

### MUI 제거

`@mui/material`, `@mui/icons-material`, `@mui/x-data-grid`, `@emotion/*` 의존성을 모두 뺐다. 대신 `src/ui`에 자체 부품 묶음을 두었다.

- **부품:** Button, IconButton, Segmented, Switch, Field, TextInput, TextArea, Select, Card, Tabs, Dialog, Notice, Tag, Spinner
- **스타일:** 디자인 토큰(`src/ui/tokens.css`, CSS 변수)만 쓰는 CSS 모듈
- **다크 모드:** `<html data-theme>` + `useDocumentTheme`
- **콘텐츠 스크립트:** 모아보기 컨테이너는 `tbcv2-` 접두사 CSS로 호스트 테마를 따른다.

디자인 규칙은 `docs/design-system.md`에 있다.

| 번들 | 이전 | 이후 |
|---|---|---|
| 설정 페이지 | 1,363KB | 844KB |
| 콘텐츠 스크립트(각) | ~523KB | ~425KB |
| 전체 | 3.33MB | 2.36MB |

### 주요 파일

- **필터 목록:** `src/components/filter/FilterList.tsx`가 DataGrid를 대체한다. 페이지당 개수는 storage.local의 `filterListPageSize`에 둔다.
- **필터 시험:** `src/components/filter/FilterTester.tsx`. 판정은 실제 수집과 같은 `evaluateFilterGroup`이다.
  - 줄 상태: include / exclude / partial / miss / inactive
  - partial은 '맞음' 조건이 하나 이상 맞았을 때만이다. '아님'만 맞은 경우는 miss다.
- **템플릿 모양:** 고른 모양은 따로 저장하지 않고 템플릿 문자열에서 거꾸로 알아낸다.
- **트위치 스크롤:** newest-bottom에서만 MutationObserver와 이미지 로드를 보고 바닥에 붙인다. 치지직(column-reverse)은 그대로다.
- **트위치 트림:** newest-bottom에서 prevKey가 null이면 버퍼 끝에 붙인다.
- **클린봇:** `.tbc-chat-cleanbot[open]::details-content { display: contents; }`
- **번역:** `filter_list.*`와 `filter_test.*` 키를 11개 언어에 추가했다. `_locales`에는 `close`와 `back`을 추가했다.
