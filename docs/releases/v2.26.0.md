# v2.26.0

v2.25.3 이후 변경 사항. 치지직 닉네임 필터를 닉네임 글자가 아니라 사람(ID)으로 지정할 수 있게 했다.

## 1. 릴리스 노트

```
v2.26.0

- 치지직 닉네임 필터에서 사용자를 선택할 수 있도록 개선 (닉네임이 바뀌어도 계속 적용)
- 치지직 채팅에서 닉네임을 누르면 뜨는 프로필 창에 **ID 복사** 버튼 추가
```

## 2. 변경

- **닉네임 필터를 사람으로** (`src/interfaces/filter.ts`, `src/filter/evaluate.ts`, `src/platform/chzzk.ts`, `src/platform/chzzk-socket.ts`):
  - 치지직은 채팅의 사용자 ID(`userIdHash`)가 그 사람의 채널 ID와 같다. 그래서 채널 검색, 채널 정보 API(`src/api/chzzk-channel.ts`)를 그대로 쓴다.
  - 이름 조건에 `userId`, `userImage`를 더한다. `userId`가 있으면 `value`(닉네임)는 표시용이고 판정은 ID로 한다. 같은 닉네임의 다른 사람은 안 맞는다.
  - 채팅의 ID: 소켓 경로는 `chat.uid`, HTML 경로는 host key 앞부분(`userIdFromHostKey`). 익명 후원은 넣지 않는다. 채팅에서 ID를 못 꺼내면 예전처럼 닉네임으로 맞춘다.
  - 같은 ID면 닉네임이 달라도 중복 필터로 본다(`src/filter/duplicate.ts`).
- **닉네임 칸** (`src/components/filter/NicknameInput.tsx`): 새 필터 추가(기본, 고급)와 조건 수정 대화상자가 같이 쓴다.
  - 글자를 치면 사용자 검색 결과가 칸 아래에 뜬다. 고르면 프로필 사진과 닉네임 칩이 되고 ✕로 지운다. 화살표와 Enter로도 고른다.
  - 채널 주소나 32자리 ID를 붙여 넣으면 그 사람으로 바로 고른다.
  - 고르지 않고 적은 글자는 예전과 같은 닉네임 조건이다. 채널 검색 색인에 없는 시청자가 있어서다(실측 5명 중 2명).
  - 치지직 탭도 권한도 없으면 결과 자리에 "권한 허용하고 검색" 버튼을 띄운다. 허용하면 적어 둔 글자로 바로 찾는다. `api.chzzk.naver.com`은 필수 권한으로 옮기지 않았다. 업데이트 때 새 권한 경고가 생기면 Chrome이 기존 사용자의 확장을 끈다.
  - 이름표 오른쪽에 "닉네임 검색 또는 ID 입력이 가능합니다" 한 줄(치지직 닉네임 조건만). 공용 `Field`에 `hint`를 더했다.
  - 필터 목록에서 사람으로 고른 조건은 `@` 대신 프로필 사진을 붙인다.
- **프로필 창 ID 복사** (`src/content-scripts/chzzk/profile-actions.ts`): 원래 채팅에서 닉네임을 누르면 뜨는 프로필 창의 버튼 목록 끝에 "ID 복사"를 붙인다.
  - 창에는 사용자 ID가 없어 닉네임을 누르는 순간 그 채팅의 host key에서 꺼내 둔다.
  - 창이 들어오는 순간 MutationObserver로 붙여서 버튼이 늦게 붙지 않는다. 버튼 모양은 창에 원래 있던 버튼의 class를 빌린다.
  - 치지직이 창 높이를 잰 뒤에 붙으므로, 아래쪽 채팅에서 연 창은 넘친 만큼 올린다.
  - 선택자는 OTA `profilePopup`, `profilePopupActions`로 바꿀 수 있다. 번들 JSON에는 넣지 않았다(기본값은 코드에).
  - 처음엔 창에서 바로 "채팅 수집", "채팅 제외"를 켜고 끄게 만들었다가 걷었다. 그 사람이 든 배열 필터, 닉네임으로만 넣은 필터, 채널 지정 필터와 겹칠 때 창에 보일 상태가 복잡해져서 필터 설정은 설정 페이지에서만 한다.
- **초기화 버튼** (`FilterInputForm.tsx`): 내용 칸 옆 아이콘이라 그 칸만 비우는 버튼처럼 보였다. 폼 맨 아래 "필터 추가" 왼쪽 글자 버튼으로 옮긴다. 배지를 고른 뒤 닉네임이나 키워드로 돌아가는 길은 그대로다.
- **입력 칸 여백** (`src/ui`): 오른쪽 아이콘만 있는 칸에도 왼쪽 여백 36px이 붙어 글자가 밀려 있었다. 아이콘이 있는 쪽만 띄운다.
- **치지직 배지 목록 캐시** (`src/utils/badgeCache.ts`): 7일에서 1시간으로. 목록에 새 배지를 넣어도 최근 7일 안에 배지 화면을 연 사용자는 옛 목록을 봤다.
- **업데이트 시험 스크립트** (`scripts/real-update-test.mjs`, 확장에는 안 들어감): `--socket off`가 설치별 숫자만 99로 두어, OTA `socketRenderPercent`가 100인 지금은 소켓 모드로 돌았다. 지난 릴리스들의 "소켓 끔" 시험도 HTML 경로가 아니었다. 치지직 페이지 스위치(`tbc:socket-render`)로 고정한다.

참고: 닉네임 필터 본체와 UI 수정 커밋 셋은 다른 세션의 커밋 `fb59ad5`(ops: 사이트 스트리머별 구독 배지 페이지 데이터...)에 합쳐져 올라갔다. 커밋 목록만 보면 이 기능이 안 보인다.

## 3. 확인

- **테스트:** vitest 538개 통과, tsc 오류 없음
- **라이브 판정(닉네임을 일부러 틀리게, ID만 맞게 넣은 필터):** 소켓 모드 10/10, HTML 경로 3/3 수집, 다른 사람 0
- **설정 화면:** 검색해서 고르기, 주소 붙여 넣기, 닉네임만 적기가 각각 맞게 저장됨. 글자를 천천히 쳐서 중간에 검색이 돌아도 포커스와 글자 유지. 다크 모드, 권한 없음(허용 버튼), 치지직 탭 있음(결과 바로 뜸)
- **프로필 창:** 라이브에서 소켓 켬, 끔 모두 버튼이 붙고 클립보드에 ID가 들어감. 1.5초 뒤 문구 복귀. 복사한 ID를 설정에 붙여 넣으면 사람 칩. 창이 보인 프레임 중 버튼 없는 프레임 0(5회)
- **확인 못 함:**
  - 다시보기의 ID 복사. 시험 환경의 Chromium이 영상을 못 틀어 채팅이 나오지 않았다. 코드 경로는 라이브와 같다
  - 권한 창에서 실제로 허용을 누르는 마지막 단계. 채널 검색 버튼과 같은 함수를 쓴다
- **실제 업데이트(Chrome 업데이터, 스토어 v2.25.3 zip → 빌드 28ee162):** 소켓 켬/끔 × 채팅 유지 저장 켬/끔 네 조합 모두. 이후 커밋은 설정 페이지만 바꿨다
  - 업데이트: 창 하나, 이전 채팅 그대로(3~100개 전부 유지), 안내 띠 없음, 60초 동안 수집 계속(새 채팅 8~11개)
  - 빈틈 7초: 끊긴 동안 채팅 수 유지, 그 뒤 안내 띠
  - 업데이트 도중 0.2초 창이 없는 순간이 한 번 잡힌다. 이미 나간 v2.25.2 → v2.25.3에서도 똑같아서 원래 있던 창 교체 순간이다
