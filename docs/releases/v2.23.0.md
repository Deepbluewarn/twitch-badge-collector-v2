# v2.23.0

v2.22.0(2026-10-18 배포, `1a02a01`) 이후 변경 사항. 필터가 수십~수백 개인 사람을 위한 기능과 채널별로 확장 끄기.

## 1. 릴리스 노트

GitHub Release 본문과 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣는다.

```
v2.23.0

- 채널별로 확장 끄기 기능 추가
- 치지직 채널 검색 기능 추가
- 필터 목록을 채널별로 보는 기능 추가

```

## 2. 달라진 점 안내

### 채널별로 확장 끄기

방송 페이지에서 팝업을 열면 맨 위에 지금 채널이 나온다. `이 채널에서 사용`을 끄면 그 채널에서는 확장이 없는 것처럼 동작한다.

- 모아보기 창, 원본 채팅의 수집 표시, 채팅창 좌우 바꾸기, 포인트 자동 받기를 하지 않는다.
- 새로고침 없이 바로 적용된다.
- 꺼진 채널에서는 확장 아이콘이 흑백이 된다.
- 꺼진 채널은 팝업 → 일반 설정 아래 `꺼진 채널`에서 다시 켤 수 있다. 8개를 넘으면 검색 칸이 생긴다.
- 라이브 페이지 기준이다. 다시보기에서는 나오지 않는다.

### 치지직 채널 검색

필터의 채널을 지정할 때(채널 수정, 새 필터 추가) 채널 이름으로 찾아 고를 수 있다. 고르면 채널 ID·이름·프로필 사진이 채워진다.

- 치지직 탭이 열려 있으면 바로 검색된다.
- 치지직 탭이 없으면 처음 한 번 브라우저가 `api.chzzk.naver.com` 접근을 묻는다.
- 트위치는 지원하지 않는다.

필터 목록의 채널에는 프로필 사진이 붙고, 마우스를 올리면 나오는 ↗로 채널 페이지를 연다.

### 채널별 보기

채널을 지정한 필터가 있으면 필터 목록 왼쪽에 채널 목록이 생긴다.

- 항목은 `모든 필터` / `채널 지정 안 함 (공통)` / 채널마다다.
- 채널이 8개를 넘으면 검색 칸이 생긴다.
- 채널을 지정한 필터가 없으면 채널 목록은 나오지 않는다.

### 필터 찾기

필터 목록 머리의 🔍를 누르면 검색 칸이 펼쳐진다. 키워드, 닉네임, 배지 이름, 채널 이름, 메모에서 찾는다.

### 범위가 넓은 필터 · 중복 필터

- **범위 넓음 (노랑):** 조건이 전부 `아님`이거나 비어 있어 사실상 모든 채팅을 모으는 포함 필터. 누르면 "대부분의 채팅이 수집됩니다."가 뜬다.
- **중복 (회색):** 플랫폼·채널·조건이 같은 필터. 포함/제외만 다른 것도 같은 필터로 본다. 제외가 늘 이기기 때문이다.
- 머리 줄의 `범위가 넓은 필터 N개` / `중복 필터 N개`를 누르면 그 필터만 보인다. 중복은 같은 것끼리 붙여서 보여 준다.

### 필터 삭제 되돌리기

`선택 삭제` 뒤 8초 동안 "필터 N개를 삭제했습니다. [되돌리기]"가 뜬다. 누르면 원래 자리에 다시 들어간다.

## 3. 개발 변경 사항

### 권한

| 권한 | 용도 | 설치·업데이트 경고 |
|---|---|---|
| `declarativeNetRequestWithHostAccess` | 이 확장의 `api.chzzk.naver.com` 요청에서만 Origin 헤더 제거 | 없음 |
| `https://api.chzzk.naver.com/*` (optional) | 치지직 탭이 없을 때 채널 검색. 처음 검색할 때 요청한다 | 없음 (요청 시 묻는다) |

MV2(Firefox)에서는 `optional_host_permissions`가 없어서, `wxt.config.ts` hook이 `optional_permissions`로 옮긴다. Firefox 113 미만에서는 DNR이 없어 직접 요청 경로가 동작하지 않는다(lint notice 2개).

`api.chzzk.naver.com`은 브라우저 요청을 `*.chzzk.naver.com` 출처에서만 받는다. 다른 출처는 403이다. 그래서 두 경로를 쓴다.
1. 치지직 탭이 있으면 그 탭의 콘텐츠 스크립트가 탭 출처로 부른다. Firefox는 `content.fetch`를 쓴다.
2. 탭이 없으면 확장에서 직접 부르고, DNR 규칙으로 이 확장 요청의 Origin만 지운다. 규칙은 `initiatorDomains`로 이 확장에 한정한다.

### 주요 파일

- `src/api/chzzk-channel.ts`: 검색, 채널 정보, 탭 경유, DNR 규칙
- `src/components/filter/ChannelSearch.tsx`, `ChannelRail.tsx`, `FilterSearch.tsx`
- `src/filter/broad.ts`: 어떤 조건과도 겹치지 않는 채팅을 `evaluateFilterGroup`에 넣어 판정
- `src/filter/duplicate.ts`, `src/filter/search.ts`
- `src/utils/channel-off.ts`, `src/content-scripts/base/channel-off.ts`
  - storage.local `disabledChannels`
  - `<html class="tbcv2-channel-off">`로 숨긴다
  - 꺼진 채널에선 init이 컨테이너를 만들지 않는다
  - background가 탭별 흑백 아이콘을 OffscreenCanvas로 만든다
- `src/hooks/useAlert.ts`, `src/interfaces/alert.ts`: 알림에 `action`(글자 버튼)과 `ttl`
- 필터에 `filterChannelImage` 필드가 추가됐다. 가져오기·내보내기는 그대로 호환된다.

### 넣었다가 뺀 것

원본 채팅 우클릭 `필터 시험에 넣기`(`0bb3894`)는 `3dbe0f1`에서 되돌렸다. 쓰임새가 좁은 데 비해 Chrome에서는 우클릭할 때마다 메뉴 항목이 보이는 비용이 있어서다.
